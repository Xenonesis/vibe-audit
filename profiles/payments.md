# Payments / Commerce Profile

Use for checkout, subscriptions, credits, refunds, coupons, inventory, or fulfillment.

Server must be authoritative for price, currency, discount, tax, inventory, entitlement, and fulfillment. Verify webhook signatures/replay/idempotency, duplicate fulfillment, refund state, money precision/rounding, ownership, and invalid workflow transitions. Payment architecture/provider replacement is HIGH change risk.

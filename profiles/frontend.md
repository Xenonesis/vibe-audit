# Frontend Profile

Use for browser-heavy React/Vue/Svelte/Next/Nuxt/etc. tasks.

Prioritize client/server trust boundaries, XSS/CSRF where applicable, authz assumptions in UI, hydration/rendering correctness, bundle/waterfall/image/font performance, fake success states, accessibility, and runtime console/network errors. Load `runtime-ui`, `accessibility`, or `seo` only when in user scope.

# Anti-Slop & Visual Integrity Reference

Load when auditing frontend user interfaces, marketing pages, design tokens, copy, or during FULL POLISH and UI reviews.

## Purpose

Detect, prohibit, and replace AI-generated visual slop, cartoon emojis, and cliché marketing copy tropes. Enforce high-signal, professional technical design standards over generic AI artifacts.

---

## 1. Cartoon & Decorative Emojis

Decorative cartoon emojis in technical/production interfaces degrade trust and signal unpolished AI generation.

### Banned Emojis
`🚀`, `🔥`, `🤖`, `✨`, `🧠`, `💡`, `🦄`, `⚡`, `🎉`, `🥳`, `🤯`, `💥`, `🔮`, `🪄`, `🌟`, `⭐`, `🙌`, `💪`, `🎯`

### Replacement Policy
Do not leave raw emoji glyphs in headers, feature lists, badges, or buttons. Replace with semantic icons or crisp typographic tags:

| Banned Emoji | Recommended Replacement |
|---|---|
| `🚀` (Launch / Fast) | Lucide `<Rocket />`, `<Zap />`, or text tag `[DEPLOY]` / `Fast` |
| `🔥` (Popular / Hot) | Lucide `<Flame />`, `<TrendingUp />`, or badge `POPULAR` |
| `🤖` (AI / Bot) | Lucide `<Cpu />`, `<Terminal />`, `<Bot />`, or label `Automated` |
| `✨` (Magic / New) | Lucide `<Sparkles />`, `<CheckCircle />`, or badge `NEW` / `PRO` |
| `🧠` (Smart / Intelligence) | Lucide `<BrainCircuit />`, `<Layers />`, or text `Analysis` |
| `💡` (Tip / Idea) | Lucide `<Lightbulb />`, `<Info />`, or alert header `NOTE` |
| `⚡` (Performance / Instant) | Lucide `<Zap />`, `<Activity />`, or metric `< 5ms` |
| `🎉` / `🥳` (Success) | Lucide `<Check />`, `<CheckCircle2 />`, or status `Complete` |
| `🎯` (Target / Goal) | Lucide `<Target />`, `<Crosshair />`, or label `Objective` |

**Severity**: `MEDIUM` | **Change Risk**: `LOW`

## 2. AI Slop UI & Visual Anti-Patterns

Vibe-coded interfaces frequently rely on repetitive visual tropes generated by default prompts.

### Banned Visual Patterns
1. **Blurry Glow Backdrop Orbs**:
   - `blur-3xl`, `blur-2xl`, `rounded-full bg-purple-600/30 blur-[100px]`.
   - *Fix*: Remove artificial glowing orbs. Use clean, architectural grid backgrounds or stark high-contrast canvas (`#0A0B0E` / `#F4F4F0`).
2. **Cliché Purple/Indigo Gradients**:
   - `bg-gradient-to-r from-purple-500 to-indigo-500`, `from-violet-600 to-fuchsia-600`.
   - *Fix*: Use purposeful solid accent fills (e.g. Cobalt `#2563EB`, Emerald `#16A34A`, Terminal Amber `#F59E0B`).
3. **Fuzzy Colored Glow Shadows**:
   - `shadow-purple-500/50`, `shadow-[0_0_50px_rgba(...)]`.
   - *Fix*: Replace with hard offset architectural shadows (`box-shadow: 3px 3px 0px #000000`) or clean 1px borders (`border border-neutral-800`).
4. **Sparkle AI Pills**:
   - Pill capsules with `border-radius: 9999px` containing `✨ AI Powered ✨`.
   - *Fix*: Sharp rectangular tag `border border-neutral-700 font-mono text-xs uppercase px-2 py-0.5`.

**Severity**: `MEDIUM` | **Change Risk**: `LOW`

## 3. AI Slop Copy & Marketing Tropes

AI generators frequently emit generic, repetitive marketing filler instead of concrete product capabilities.

### Banned Copy Tropes
- "In today's fast-paced world..."
- "Delve into..."
- "Unlock the power of..."
- "Harness the potential of..."
- "Seamlessly integrate..."
- "Game-changer for..."
- "Elevate your workflow..."
- "A testament to..."
- "Breathe life into..."

### Replacement Rule
Replace vague puffery with exact technical specifications, benchmark numbers, or direct verbs:
- *Bad*: "Unlock the power of seamless AI-driven testing."
- *Good*: "Deterministic static analysis with 47 preflight rule checks."

**Severity**: `LOW` | **Change Risk**: `LOW`

---

## 4. Audit Finding Model

When reporting slop findings:
- **Finding**: `[ANTI-SLOP] <Specific pattern>` (e.g. `[ANTI-SLOP] Cartoon emoji used in UI element`, `[ANTI-SLOP] Blurry glow orb backdrop detected`).
- **Category**: `AI Slop / Visual Integrity`
- **Severity**: `MEDIUM` (Emojis / Glow tropes) | `LOW` (Marketing filler copy)
- **Evidence**: Component file, line number, exact string/class.
- **Remediation**: Specific replacement component, SVG icon, or clean CSS/Tailwind class.

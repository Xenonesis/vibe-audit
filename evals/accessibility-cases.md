# Accessibility Cases

Use only when accessibility is in scope or FULL POLISH includes it.

- A11Y-01: unlabeled form control fixture should be identified with concrete DOM evidence.
- A11Y-02: do not claim full WCAG conformance from one static fixture.
- A11Y-03: where runtime verification is available, keyboard/focus behavior should be tested rather than guessed.
- A11Y-04: accessibility remediation must preserve form semantics and business behavior.

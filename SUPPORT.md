# Support

Vibe-Coding Polisher is a portable skill package, not a managed security service.

## Best support request
Include:
- package version from `VERSION`
- host/harness and exact version
- operating system/runtime
- requested mode/profile
- whether the repository was trusted or sandboxed
- failing command/eval id
- redacted logs or `grading.json`
- expected vs actual behavior

Never attach production secrets or full credential files.

## Compatibility
Host behavior changes frequently. Documentation under `adapters/` is guidance; `metadata/compatibility.json` records confidence, freshness, and behavioral-test status.
